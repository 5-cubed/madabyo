# Plan: Pick a Folder (SEQ-001) + Picker Cancelled (SEQ-004)

**Type:** Self-Plan

## Scope
- Design unit: SEQ-001 "Pick a folder" (REQ-001) **and** SEQ-004 "Picker cancelled" (REQ-004), both against the same two components — CMP-001 (WorkspaceController), CMP-002 (FolderPicker).
- Flow (SEQ-001's happy path and SEQ-004's cancel path are the same two arrows, differing only in `pickFolder()`'s return value):
  ```
  User
    |
    v
  WorkspaceController.openFolder()
    |
    v
  FolderPicker.pickFolder() --> handle | null
    |
    v
  WorkspaceController (state updated | state unchanged)
  ```
- This plan covers only the two arrows above: the user-triggered entry point and the controller-to-picker call. `FolderHandleStore` persistence, `SidebarTree`, and `SplitContainer` are out of scope — later SEQs.
