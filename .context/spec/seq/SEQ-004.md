# SEQ-004 Picker cancelled
- Status: Draft

## Requirement
REQ-004

## Components
- WorkspaceController (CMP-001)
- FolderPicker (CMP-002)

## Flow
WorkspaceController.openFolder()
  |
  v
FolderPicker.pickFolder() --> null
  |
  v
WorkspaceController (state unchanged)

## Sequence
1. WorkspaceController calls FolderPicker's `pickFolder(): Promise<FileSystemDirectoryHandle | null>`.
2. The user dismisses the native picker without granting access, so `pickFolder()` resolves `null`.
3. WorkspaceController detects the `null` result and leaves its folder/tree state as it was (empty/prompt), without calling TreeScanner.

## Acceptance Criteria
1. A `null` result from `pickFolder()` never reaches TreeScanner's `scanTree()`.
2. WorkspaceController's state after cancellation matches its state before `openFolder()` was called.
