# SEQ-013 Open multiple files as separate tabs
- Status: Draft

## Requirement
REQ-013

## Components
- SidebarTree (CMP-005)
- PaneManager (CMP-009)
- TabManager (CMP-008)

## Flow
SidebarTree (onSelectFile) x N
  |
  v
PaneManager.openFile(paneId, fileHandle) x N
  |
  v
TabManager.tabs grows by 1 each time (for not-yet-open files)

## Sequence
1. The user clicks a sequence of distinct, not-yet-open markdown files in SidebarTree.
2. Each click drives one `PaneManager.openFile(paneId, fileHandle)` call (SEQ-009), each resulting in one `TabManager.openTab()` append.
3. TabManager's `tabs` getter reflects one new entry per distinct file, in the order they were opened.

## Acceptance Criteria
1. After N distinct file clicks, `tabs.length === N`.
2. `tabs` order matches the order the files were clicked.
