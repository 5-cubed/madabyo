# SEQ-005 Unsupported browser
- Status: Draft

## Requirement
REQ-005

## Components
- WorkspaceController (CMP-001)
- FolderPicker (CMP-002)
- SidebarTree (CMP-005)

## Flow
WorkspaceController.openFolder()
  |
  v
FolderPicker.isSupported() --> false
  |
  v
<SidebarTree status="unsupported" />

## Sequence
1. Before calling `pickFolder()`, WorkspaceController calls FolderPicker's `isSupported(): boolean`.
2. When `isSupported()` returns `false`, WorkspaceController does not invoke `pickFolder()`.
3. WorkspaceController renders `<SidebarTree status="unsupported" ... />`, which shows the unsupported-browser message.

## Acceptance Criteria
1. `pickFolder()` is never called when `isSupported()` returns `false`.
2. SidebarTree displays the unsupported-browser message when `status="unsupported"`.
