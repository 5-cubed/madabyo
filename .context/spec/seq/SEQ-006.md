# SEQ-006 Empty markdown result
- Status: Draft

## Requirement
REQ-006

## Components
- WorkspaceController (CMP-001)
- TreeScanner (CMP-003)
- SidebarTree (CMP-005)

## Flow
TreeScanner.scanTree(handle) --> TreeNode (empty)
  |
  v
<SidebarTree status="empty" />

## Sequence
1. TreeScanner's `scanTree()` resolves a `TreeNode` with zero markdown entries because the granted folder has none.
2. WorkspaceController sets its status to `"empty"` instead of `"ready"`.
3. WorkspaceController renders `<SidebarTree tree={TreeNode} status="empty" ... />`, which shows the "no markdown files found" message.

## Acceptance Criteria
1. An empty `TreeNode` result sets `status="empty"`, never `"ready"`.
2. SidebarTree renders the "no markdown files found" message when `status="empty"`, and throws no error.
