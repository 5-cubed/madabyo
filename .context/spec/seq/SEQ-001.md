# SEQ-001 Pick a folder
- Status: Draft

## Requirement
REQ-001

## Components
- WorkspaceController (CMP-001)
- FolderPicker (CMP-002)

## Flow
User
  |
  v
WorkspaceController.openFolder()
  |
  v
FolderPicker.pickFolder()

## Sequence
1. WorkspaceController's `openFolder(): Promise<void>` runs in response to the user's "Open Folder" action.
2. WorkspaceController calls FolderPicker's `pickFolder(): Promise<FileSystemDirectoryHandle | null>`, which invokes the browser's native picker.
3. On a granted handle, WorkspaceController stores it in its own state and proceeds to the scan step (SEQ-002).

## Acceptance Criteria
1. Invoking `openFolder()` results in exactly one `pickFolder()` call.
2. A non-null return from `pickFolder()` is held as the controller's current folder handle.
