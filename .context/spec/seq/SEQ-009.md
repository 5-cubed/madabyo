# SEQ-009 Open or focus a tab for a clicked file
- Status: Draft

## Requirement
REQ-009

## Components
- SidebarTree (CMP-005)
- PaneManager (CMP-009)
- TabManager (CMP-008)

## Flow
SidebarTree (onSelectFile)
  |
  v
PaneManager.openFile(paneId, fileHandle)
  |
  v
TabManager.openTab(fileId, renderResult)

## Sequence
1. SidebarTree's `onSelectFile(fileHandle)` callback fires when the user clicks a markdown file node.
2. The active pane's PaneManager calls its own `openFile(paneId, fileHandle): Promise<void>`, which first checks that pane's TabManager for an existing tab with this file's id.
3. If no existing tab is found, PaneManager renders the file (SEQ-008) and calls TabManager's `openTab(fileId, renderResult): void` to append and activate a new tab; if one is found, PaneManager skips rendering and calls TabManager's `focusTab(fileId): void` directly (SEQ-012 covers TabManager's own internal dedup guard as a backstop).

## Acceptance Criteria
1. Clicking a file not yet open in the active pane results in `tabs.length` increasing by one and the new tab active.
2. Clicking a file already open in the active pane leaves `tabs.length` unchanged and makes the existing tab active.
