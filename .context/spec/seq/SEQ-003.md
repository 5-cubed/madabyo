# SEQ-003 Render the sidebar tree
- Status: Draft

## Requirement
REQ-003

## Components
- WorkspaceController (CMP-001)
- SidebarTree (CMP-005)
- ThemeTokens (CMP-006)

## Flow
WorkspaceController
  |
  v
<SidebarTree tree status onSelectFile />
  |
  v
ThemeTokens (CSS custom properties)

## Sequence
1. WorkspaceController renders `<SidebarTree tree={TreeNode} status="ready" onSelectFile={...} />` once a scan completes.
2. SidebarTree's stylesheet reads ThemeTokens' CSS custom properties (`--color-editor-bg`, `--color-sidebar-bg`, `--color-ink`, `--color-accent`) for its light-theme colors.
3. SidebarTree renders each folder/file node with the corresponding VS Code icon asset.

## Acceptance Criteria
1. Every folder node in the rendered sidebar shows the VS Code folder icon; every markdown file node shows the VS Code markdown-file icon.
2. The rendered sidebar's colors match ThemeTokens' values, not any other palette.
