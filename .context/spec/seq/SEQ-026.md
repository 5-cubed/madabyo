# SEQ-026 Fall back when the persisted folder no longer exists
- Status: Draft

## Requirement
REQ-026

## Components
- WorkspaceController (CMP-001)
- FolderHandleStore (CMP-004)
- TreeScanner (CMP-003)
- SidebarTree (CMP-005)

## Flow
WorkspaceController.resumeFolder()
  |
  v
TreeScanner.scanTree(handle) --throws (folder gone)-->
  |
  v
<SidebarTree status="empty" />

## Sequence
1. WorkspaceController retrieves a handle via FolderHandleStore's `loadHandle()` and permission passes `verifyPermission()`, so it proceeds to TreeScanner's `scanTree(handle)`.
2. `scanTree()` fails because the underlying folder no longer exists at that location; WorkspaceController catches this failure rather than letting it propagate.
3. WorkspaceController falls back to the same `status="empty"` / open-folder-prompt state used for a session with no persisted handle at all.

## Acceptance Criteria
1. A `scanTree()` failure caused by a missing folder is caught and does not crash the app.
2. The resulting UI state is identical to a fresh session's empty/open-folder prompt state.
