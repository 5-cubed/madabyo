# SEQ-007 Large-tree scan stays responsive
- Status: Draft

## Requirement
REQ-007

## Components
- WorkspaceController (CMP-001)
- TreeScanner (CMP-003)
- SidebarTree (CMP-005)

## Flow
WorkspaceController (status="loading")
  |
  v
TreeScanner.scanTree(handle)  [async, non-blocking]
  |
  v
WorkspaceController (status="ready")

## Sequence
1. WorkspaceController sets its status to `"loading"` immediately before calling TreeScanner's `scanTree()`.
2. WorkspaceController renders `<SidebarTree status="loading" ... />`, which shows the loading indicator, while `scanTree()`'s promise-based async traversal runs without blocking the main thread.
3. On resolution, WorkspaceController sets status to `"ready"` (or `"empty"`) and re-renders SidebarTree with the resulting tree.

## Acceptance Criteria
1. `status` is `"loading"` for the full duration between calling `scanTree()` and its resolution.
2. The page remains interactive (clickable/scrollable) while `status === "loading"`.
