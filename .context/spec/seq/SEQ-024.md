# SEQ-024 Retrieve and re-scan a persisted handle on load
- Status: Draft

## Requirement
REQ-024

## Components
- WorkspaceController (CMP-001)
- FolderHandleStore (CMP-004)
- TreeScanner (CMP-003)
- SidebarTree (CMP-005)

## Flow
App load
  |
  v
WorkspaceController.resumeFolder()
  |
  v
FolderHandleStore.loadHandle() --> handle
  |
  v
TreeScanner.scanTree(handle)
  |
  v
<SidebarTree status="ready" />

## Sequence
1. On app load, WorkspaceController calls its own `resumeFolder(): Promise<void>`.
2. `resumeFolder()` calls FolderHandleStore's `loadHandle(): Promise<FileSystemDirectoryHandle | null>`; if it resolves a handle (and permission checks pass, SEQ-025), WorkspaceController does not call FolderPicker's `pickFolder()`.
3. WorkspaceController calls TreeScanner's `scanTree(handle)` (same as SEQ-002) and renders `<SidebarTree status="ready" .../>` from the result, without ever invoking the native picker.

## Acceptance Criteria
1. When `loadHandle()` resolves a non-null handle with valid permission, `pickFolder()` is never called during that load.
2. The sidebar populates from `scanTree(handle)`'s result using the same logic path as REQ-002.
