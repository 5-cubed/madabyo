# SEQ-011 File-not-found for a moved/deleted file
- Status: Draft

## Requirement
REQ-011

## Components
- PaneManager (CMP-009)
- MarkdownRenderer (CMP-007)
- TabManager (CMP-008)
- Pane (CMP-010)

## Flow
MarkdownRenderer.renderFile(handle) --read fails-->
  |
  v
{ status: 'not-found' }
  |
  v
TabManager.openTab(fileId, { status: 'not-found' })
  |
  v
<Pane /> (renders not-found state)

## Sequence
1. MarkdownRenderer's `renderFile()` catches a failed read caused by the file no longer existing at its handle's location and resolves `{ status: 'not-found' }`.
2. PaneManager's `openFile()` passes this result to TabManager's `openTab(fileId, renderResult)`.
3. Pane renders the file-not-found state for any tab entry with `status: 'not-found'`.

## Acceptance Criteria
1. A read failure due to a missing file never crashes the app.
2. The affected tab shows the file-not-found state, not a blank tab.
