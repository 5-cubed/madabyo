# SEQ-015 Close a tab
- Status: Draft

## Requirement
REQ-015

## Components
- Pane (CMP-010)
- TabManager (CMP-008)

## Flow
<Pane onCloseTab={fileId} />
  |
  v
TabManager.closeTab(fileId)

## Sequence
1. Pane's `onCloseTab(fileId)` callback fires when the user activates a tab's close control.
2. Pane's parent calls that pane's TabManager's `closeTab(fileId): void`.
3. TabManager removes the entry for `fileId` from its tab list; if `fileId` was not the active tab, `activeTabId` is unchanged.

## Acceptance Criteria
1. After `closeTab(fileId)`, no entry in `tabs` has that `fileId`.
2. Closing a non-active tab leaves `activeTabId` pointing at the same tab as before.
