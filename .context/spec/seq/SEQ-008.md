# SEQ-008 Read and render a file's markdown content
- Status: Draft

## Requirement
REQ-008

## Components
- PaneManager (CMP-009)
- MarkdownRenderer (CMP-007)

## Flow
PaneManager.openFile(paneId, fileHandle)
  |
  v
MarkdownRenderer.renderFile(fileHandle)
  |
  v
{ status: 'ok', html }

## Sequence
1. PaneManager's `openFile(paneId, fileHandle): Promise<void>` calls MarkdownRenderer's `renderFile(handle: FileSystemFileHandle): Promise<{status, html?}>`.
2. MarkdownRenderer reads the file's raw text via the handle and renders it to HTML with the chosen markdown-rendering library.
3. MarkdownRenderer resolves `{ status: 'ok', html }`, which PaneManager passes to the tab-open step (SEQ-009).

## Acceptance Criteria
1. `renderFile()` reads the file's text before producing any HTML.
2. The resolved `html` reflects the source markdown's structure (headings, lists, code blocks).
