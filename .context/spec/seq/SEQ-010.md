# SEQ-010 Malformed markdown render failure
- Status: Draft

## Requirement
REQ-010

## Components
- PaneManager (CMP-009)
- MarkdownRenderer (CMP-007)
- TabManager (CMP-008)
- Pane (CMP-010)

## Flow
MarkdownRenderer.renderFile(handle) --throws-->
  |
  v
{ status: 'render-error' }
  |
  v
TabManager.openTab(fileId, { status: 'render-error' })
  |
  v
<Pane /> (renders error state)

## Sequence
1. MarkdownRenderer's `renderFile()` catches a parser exception internally and resolves `{ status: 'render-error' }` instead of throwing out to its caller.
2. PaneManager's `openFile()` passes this result unchanged to TabManager's `openTab(fileId, renderResult)`.
3. Pane, driven by `tabs` prop entries from TabManager, renders the rendering-error state for any tab whose entry has `status: 'render-error'`.

## Acceptance Criteria
1. No exception from `renderFile()` propagates past PaneManager's `openFile()`.
2. A tab whose render failed shows the rendering-error state, not blank or stale content.
