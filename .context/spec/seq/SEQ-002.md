# SEQ-002 Scan, filter, and prune to markdown-only
- Status: Draft

## Requirement
REQ-002

## Components
- WorkspaceController (CMP-001)
- TreeScanner (CMP-003)

## Flow
WorkspaceController
  |
  v
TreeScanner.scanTree(handle)
  |
  v
TreeNode (markdown-only, pruned)

## Sequence
1. WorkspaceController calls TreeScanner's `scanTree(handle: FileSystemDirectoryHandle): Promise<TreeNode>` with the granted handle.
2. TreeScanner recursively walks the handle, keeps only `.md` file entries, and prunes any directory with zero markdown descendants.
3. WorkspaceController stores the resulting `TreeNode` in its state for SidebarTree to render (SEQ-003).

## Acceptance Criteria
1. The returned `TreeNode` contains every `.md` file under the root and excludes every non-markdown file.
2. Every directory node in the returned `TreeNode` has at least one markdown descendant.
