# SEQ-019 Resize panes via divider drag
- Status: Draft

## Requirement
REQ-019

## Components
- SplitContainer (CMP-011)
- PaneManager (CMP-009)

## Flow
<SplitContainer onResize={paneId, deltaPx} />  (per drag-move event)
  |
  v
PaneManager.resizeDivider(paneId, deltaPx)
  |
  v
panes[].width updated

## Sequence
1. SplitContainer translates each drag-move event on the divider into an `onResize(paneId, deltaPx)` call.
2. SplitContainer calls PaneManager's `resizeDivider(paneId: string, deltaPx: number): void` on each such event.
3. PaneManager updates the affected panes' `width` values in its `panes` state; SplitContainer re-renders both panes at their new widths without unmounting either pane's content.

## Acceptance Criteria
1. Each drag-move event's `resizeDivider()` call is reflected in `panes[].width` before the next paint.
2. Neither pane's TabManager instance is replaced or reset by a resize (its `tabs`/`activeTabId` persist unchanged).
