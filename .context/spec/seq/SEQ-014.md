# SEQ-014 Switch active tab
- Status: Draft

## Requirement
REQ-014

## Components
- Pane (CMP-010)
- TabManager (CMP-008)

## Flow
<Pane onSelectTab={fileId} />
  |
  v
TabManager.focusTab(fileId)

## Sequence
1. Pane's `onSelectTab(fileId)` callback fires when the user clicks a non-active tab.
2. Pane's parent calls that pane's TabManager's `focusTab(fileId): void`.
3. TabManager updates `activeTabId` to `fileId`; Pane re-renders showing that tab's content as active.

## Acceptance Criteria
1. After `focusTab(fileId)`, `activeTabId === fileId`.
2. Exactly one tab is marked active in the re-rendered Pane.
