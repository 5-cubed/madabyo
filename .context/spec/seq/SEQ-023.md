# SEQ-023 Persist the granted directory handle
- Status: Draft

## Requirement
REQ-023

## Components
- WorkspaceController (CMP-001)
- FolderHandleStore (CMP-004)

## Flow
WorkspaceController.openFolder() --grant obtained-->
  |
  v
FolderHandleStore.saveHandle(handle)
  |
  v
IndexedDB

## Sequence
1. After FolderPicker's `pickFolder()` resolves a non-null handle (SEQ-001), WorkspaceController calls FolderHandleStore's `saveHandle(handle): Promise<void>`.
2. FolderHandleStore writes the handle to IndexedDB before WorkspaceController proceeds to scan it (SEQ-002).
3. This write makes the handle retrievable by a later session's resume flow (SEQ-024).

## Acceptance Criteria
1. `saveHandle()` completes before the sidebar renders the scanned tree.
2. A handle written by `saveHandle()` is retrievable by FolderHandleStore's own `loadHandle()` in a subsequent call.
