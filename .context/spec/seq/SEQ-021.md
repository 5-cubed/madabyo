# SEQ-021 Collapse to single pane when one pane closes
- Status: Draft

## Requirement
REQ-021

## Components
- SplitContainer (CMP-011)
- PaneManager (CMP-009)

## Flow
<SplitContainer onClosePane={paneId} />
  |
  v
PaneManager.closePane(paneId)
  |
  v
panes.length === 1, width = 100%

## Sequence
1. SplitContainer's `onClosePane(paneId)` callback fires when the user closes one of two panes.
2. SplitContainer calls PaneManager's `closePane(paneId): void`.
3. PaneManager removes that pane entry from `panes` and sets the remaining pane's width to the full available width.

## Acceptance Criteria
1. After `closePane()`, `panes.length === 1`.
2. The remaining pane's TabManager (`tabs`, `activeTabId`) is unchanged by the other pane's closure.
