# SEQ-012 Prevent duplicate tabs for an already-open file
- Status: Draft

## Requirement
REQ-012

## Components
- TabManager (CMP-008)

## Flow
TabManager.openTab(fileId, renderResult)
  |
  v
[fileId already tracked?] --yes--> focusTab(fileId)
                          --no--> append new tab, activate it

## Sequence
1. TabManager's `openTab(fileId, renderResult): void` checks whether `fileId` already exists in its tab list, as a defensive guard regardless of what its caller already checked (SEQ-009's PaneManager checks first to avoid the unnecessary render, but TabManager must not corrupt its own list even if called directly with a duplicate `fileId`).
2. If it exists, `openTab()` delegates to its own `focusTab(fileId): void` without re-storing `renderResult` or appending anything.
3. If it doesn't exist, `openTab()` appends a new tab entry with `renderResult` and makes it active.

## Acceptance Criteria
1. Calling `openTab()` twice with the same `fileId` leaves exactly one tab for that file.
2. The second call's `renderResult` is discarded rather than overwriting the existing tab's content.
