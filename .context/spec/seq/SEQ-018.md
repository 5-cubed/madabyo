# SEQ-018 Create a second independent pane on split
- Status: Draft

## Requirement
REQ-018

## Components
- SplitContainer (CMP-011)
- PaneManager (CMP-009)
- TabManager (CMP-008)

## Flow
<SplitContainer onSplit={sourcePaneId} />
  |
  v
PaneManager.splitRight(sourcePaneId)
  |
  v
new TabManager instance (second pane)

## Sequence
1. SplitContainer's `onSplit(paneId)` callback fires when the user triggers "split right" on a pane.
2. SplitContainer awaits PaneManager's `splitRight(sourcePaneId): Promise<void>`.
3. `splitRight()` constructs a new pane entry with its own fresh TabManager instance, appends it to `panes`, and resolves once both panes are ready to render side by side.

## Acceptance Criteria
1. After `splitRight()` resolves, `panes.length` is exactly 2.
2. The new pane's TabManager starts with `tabs.length === 0`, independent of the source pane's tabs.
