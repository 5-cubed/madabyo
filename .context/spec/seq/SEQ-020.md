# SEQ-020 Clamp resize at a minimum pane width
- Status: Draft

## Requirement
REQ-020

## Components
- PaneManager (CMP-009)

## Flow
PaneManager.resizeDivider(paneId, deltaPx)
  |
  v
[newWidth < MIN_PANE_WIDTH?] --yes--> width = MIN_PANE_WIDTH

## Sequence
1. PaneManager's `resizeDivider(paneId, deltaPx): void` computes the candidate new width for the affected pane.
2. If the candidate width is below a defined `MIN_PANE_WIDTH` constant, PaneManager clamps the stored width to `MIN_PANE_WIDTH` instead of the candidate.
3. The other pane's width is adjusted complementarily so the total remains consistent, without either pane going below the minimum.

## Acceptance Criteria
1. No `resizeDivider()` call can drive a pane's stored width below `MIN_PANE_WIDTH`.
2. Repeated `resizeDivider()` calls past the clamp point leave the width pinned at `MIN_PANE_WIDTH`, not oscillating or going negative.
