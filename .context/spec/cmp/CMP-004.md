# CMP-004 FolderHandleStore
- Status: Draft

## Responsibility
Stateful wrapper around IndexedDB that persists the granted directory handle across reloads and checks/re-requests its permission.

## Mapped
- `web/src/workspace/folderHandleStore.js` — new file

## Interfaces
- `saveHandle(handle: FileSystemDirectoryHandle): Promise<void>`
- `loadHandle(): Promise<FileSystemDirectoryHandle | null>` — `null` if nothing persisted
- `verifyPermission(handle: FileSystemDirectoryHandle): Promise<'granted' | 'denied' | 'prompt'>`

## Depends On
- (none — leaf module, calls only IndexedDB and the handle's own `queryPermission`/`requestPermission`)

## Used By
- SEQ-023, SEQ-024, SEQ-025, SEQ-026
