# CMP-002 FolderPicker
- Status: Draft

## Responsibility
Stateless wrapper around the browser's File System Access API folder picker: feature-detects support and invokes the native picker.

## Mapped
- `web/src/workspace/folderPicker.js` — new file

## Interfaces
- `isSupported(): boolean`
- `pickFolder(): Promise<FileSystemDirectoryHandle | null>` — resolves `null` on cancellation

## Depends On
- (none — leaf module, calls only the browser File System Access API)
