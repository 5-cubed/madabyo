# CMP-007 MarkdownRenderer
- Status: Draft

## Responsibility
Stateless module that reads a file handle's content and renders it to HTML with a real (non-placeholder) markdown renderer, reporting parse failure or missing-file conditions instead of throwing.

## Mapped
- `web/src/workspace/markdownRenderer.js` — new file, replaces the prototype's direct `marked` call in `app/index.html`'s `openFile()`

## Interfaces
- `renderFile(handle: FileSystemFileHandle): Promise<{ status: 'ok' | 'render-error' | 'not-found', html?: string }>`

## Depends On
- (none beyond the chosen markdown-rendering library — library selection is an open ADR item, see `spec/adr/`)

## Used By
- SEQ-008, SEQ-010, SEQ-011
