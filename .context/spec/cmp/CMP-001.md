# CMP-001 WorkspaceController
- Status: Draft

## Responsibility
Top-level stateful orchestrator for the viewer: owns the current folder handle, scanned tree, loading/error state, and wires the folder-open/resume flows into the sidebar and split-pane UI.

## Mapped
- `web/src/workspace/WorkspaceController.js` (or a `useWorkspace` hook) — new file, replaces the placeholder `App.jsx` state
- `web/src/App.jsx` — becomes the component that mounts `WorkspaceController`, `SidebarTree`, and `SplitContainer`

## Interfaces
- `openFolder(): Promise<void>` — drives a fresh folder pick
- `resumeFolder(): Promise<void>` — drives the on-load resume path
