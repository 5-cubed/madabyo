# CMP-008 TabManager
- Status: Draft

## Responsibility
Stateful per-pane collection of open tabs: tracks tab order, the active tab, dedupes already-open files, and picks the next active tab when the active one closes.

## Mapped
- `web/src/panes/TabManager.js` — new file, one instance per pane

## Interfaces
- `openTab(fileId: string, renderResult: { status, html? }): void` — no-op-but-focus if `fileId` already open
- `focusTab(fileId: string): void`
- `closeTab(fileId: string): void` — auto-activates an adjacent tab if `fileId` was active
- `get tabs(): TabEntry[]`
- `get activeTabId(): string | null`

## Depends On
- (none — leaf module holding its own state)
