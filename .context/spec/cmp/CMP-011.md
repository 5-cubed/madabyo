# CMP-011 SplitContainer
- Status: Draft

## Responsibility
Stateless (props-driven) React component that renders the pane array side by side with a drag handle between them, translating drag gestures into `PaneManager.resizeDivider` calls and disabling its split trigger while a `splitRight()` call is in flight.
