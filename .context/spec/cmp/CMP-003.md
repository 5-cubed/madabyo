# CMP-003 TreeScanner
- Status: Draft

## Responsibility
Stateless recursive scan/filter/prune of a directory handle down to a markdown-only tree, using the same async traversal algorithm validated in the feasibility prototype's `raw/scan-benchmark.mjs` (56ms avg over 12,877 files).

## Mapped
- `web/src/workspace/treeScanner.js` — new file, production version of the prototype's `walkHandle` in `experiments/ide-style-markdown-viewer-feasibility/app/index.html`

## Interfaces
- `scanTree(handle: FileSystemDirectoryHandle): Promise<TreeNode>` — `TreeNode` is a pruned tree of only `.md` files and their ancestor directories (may be an empty tree)

## Depends On
- (none — leaf module, calls only the browser directory-entry iteration primitives)
