# CMP-009 PaneManager
- Status: Draft

## Responsibility
Stateful controller for the split-pane layout: holds the array of panes (each owning a `TabManager`), their widths, and the awaited split/resize/close operations — the component responsible for closing out the prototype's `splitRight()` missing-`await` race.

## Mapped
- `web/src/panes/PaneManager.js` — new file, production version of the prototype's `splitRight()` / `renderPanes()` in `app/index.html`

## Interfaces
- `openFile(paneId: string, fileHandle: FileSystemFileHandle): Promise<void>` — checks the target pane's TabManager for an existing tab first; renders via CMP-007 only for a not-yet-open file, otherwise focuses the existing tab via CMP-008 without rendering
- `splitRight(sourcePaneId: string): Promise<void>` — awaits its own layout update fully before returning, so a caller can await it before issuing another split
- `resizeDivider(paneId: string, deltaPx: number): void` — clamps to a minimum pane width
- `closePane(paneId: string): void` — collapses to the remaining pane at full width
- `get panes(): PaneState[]`
