# SCN-001 Load a workspace folder into the sidebar
- Status: Draft

## User Scenario
As a person opening the madabyo markdown viewer, I want to pick a real local folder and see it filtered down to only its markdown files, so that I can browse a large project's docs without noise from non-markdown files.

## Components
- Client/User: person opening the app in a browser, wanting to browse markdown files in a local folder
- Program/System: folder picker (File System Access API `showDirectoryPicker()`) + scan/filter/prune engine + sidebar tree renderer, VS Code icon theme, light theme
- Output/Data: sidebar tree containing only `.md` files and the directories that lead to them, rendered with VS Code folder/markdown icons in the light theme

## Flow (Interface: Client/User <-> Program/System <-> Output/Data)
1. [Client/User -> Program/System] User clicks "Open Folder" and grants access via the browser's native folder picker.
2. [Program/System -> Output/Data] System recursively scans the granted directory handle, filters to `.md` files, and prunes directories with no markdown descendants.
3. [Program/System -> Client/User] Sidebar renders the pruned tree with VS Code folder/markdown icons, in the light theme.

## Exceptions
- User cancels the picker dialog -> no folder loaded, sidebar stays in its empty/prompt state.
- Browser lacks File System Access API support -> system shows an unsupported-browser message instead of invoking the picker.
- Granted folder contains zero markdown files -> sidebar shows an empty-state message, no crash.
- Scan takes long on a large tree -> UI stays responsive (shows a loading indicator) rather than freezing.
