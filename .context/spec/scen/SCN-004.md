# SCN-004 Split the view and resize panes
- Status: Draft

## User Scenario
As a user comparing two files, I want to split the view into two independent panes and resize them, so that I can read two documents side by side.

## Components
- Client/User: user wanting to compare two files side by side
- Program/System: split-pane manager
- Output/Data: two independent panes, each with its own tab list, resizable via a drag handle

## Flow (Interface: Client/User <-> Program/System <-> Output/Data)
1. [Client/User -> Program/System] User triggers "split right" (or equivalent) on the current pane.
2. [Program/System -> Output/Data] System creates a second pane with its own independent tab list and renders both panes side by side.
3. [Client/User -> Program/System] User drags the divider between panes to resize.
4. [Program/System -> Client/User] Pane widths update live as the divider moves, without corrupting either pane's rendered content.

## Exceptions
- User drags past a minimum pane width -> resize clamps at the minimum instead of collapsing a pane to zero width.
- User closes one of the two panes -> layout returns to a single full-width pane.
- Split is triggered twice in rapid succession -> no duplicated pane DOM nodes (closes out the known prototype bug: `splitRight()` calling `renderPanes()` without `await`, which let two overlapping renders interleave and duplicate pane elements).
