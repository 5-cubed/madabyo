# SCN-005 Resume a previously opened folder
- Status: Draft

## User Scenario
As a returning user, I want the app to remember the folder I picked last time, so that I don't have to re-grant folder access on every reload.

## Components
- Client/User: returning user reopening or reloading the app
- Program/System: folder-handle persistence (IndexedDB) + permission re-request flow
- Output/Data: the same sidebar tree as the last session, without re-showing the OS folder picker

## Flow (Interface: Client/User <-> Program/System <-> Output/Data)
1. [Client/User -> Program/System] User reloads or reopens the app after a previous session picked a folder.
2. [Program/System -> Output/Data] System retrieves the persisted directory handle from IndexedDB and re-scans it.
3. [Program/System -> Client/User] Sidebar repopulates automatically with the same folder's tree, without showing the picker.

## Exceptions
- Browser has revoked or expired the handle's permission -> system prompts the user to re-grant access with a single click, rather than forcing a full re-pick.
- Persisted folder no longer exists at its original path -> system falls back to the empty/open-folder prompt state.
