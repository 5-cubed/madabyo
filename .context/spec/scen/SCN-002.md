# SCN-002 Open a markdown file into a tab
- Status: Draft

## User Scenario
As a user browsing the sidebar, I want to click a markdown file and see it rendered in a tab, so that I can read its content without leaving the app.

## Components
- Client/User: user browsing the loaded sidebar tree
- Program/System: tab manager + markdown renderer
- Output/Data: rendered markdown content shown inside an editor-style tab

## Flow (Interface: Client/User <-> Program/System <-> Output/Data)
1. [Client/User -> Program/System] User clicks a markdown file in the sidebar tree.
2. [Program/System -> Output/Data] System reads the file's content via its file handle and renders it to HTML with the chosen markdown renderer.
3. [Program/System -> Client/User] A new tab opens (or an existing tab for that file is focused) showing the rendered content in the active pane.

## Exceptions
- File content fails to parse/render (malformed markdown) -> tab shows a rendering-error state, not a crash.
- File was moved/deleted since the scan -> tab shows a file-not-found state instead of a blank tab.
- File is already open in a tab -> system focuses the existing tab instead of opening a duplicate.
