# SCN-003 Manage multiple open tabs
- Status: Draft

## User Scenario
As a user working with several files at once, I want to open multiple tabs, switch between them, and close the ones I'm done with, so that I can navigate between documents without losing my place.

## Components
- Client/User: user working with several open files in one pane
- Program/System: tab manager (per-pane tab list)
- Output/Data: list of open tabs; the active tab's rendered content shown in the pane

## Flow (Interface: Client/User <-> Program/System <-> Output/Data)
1. [Client/User -> Program/System] User opens several files in sequence, each becoming a tab in the active pane.
2. [Client/User -> Program/System] User clicks a different tab to switch, or clicks a tab's close control.
3. [Program/System -> Client/User] Clicked tab becomes active and its content is shown; a closed tab is removed from the tab list and, if it was active, an adjacent tab is auto-activated.

## Exceptions
- User closes the last tab in a pane -> pane shows an empty-state, not an error.
- User closes the currently active tab -> an adjacent tab is auto-activated deterministically (no pane left with no active tab).
