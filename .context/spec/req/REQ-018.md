# REQ-018
- Status: Draft
- Source: SCN-004 Flow steps 1 & 2

## Requirement
The system shall create a second pane with its own independent tab list when the user triggers a split, and render both panes side by side.

## Interface (Input -> Output)
- Input: a split-trigger event on an existing pane
- Output: two panes rendered side by side, each with an independent tab list

## Acceptance Criteria
- Triggering split when one pane exists results in exactly two panes.
- The new pane starts with its own tab list, independent of the source pane's.
