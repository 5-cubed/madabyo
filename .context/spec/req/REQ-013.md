# REQ-013
- Status: Draft
- Source: SCN-003 Flow step 1

## Requirement
The system shall let the user open several files in sequence, each becoming its own tab within the active pane.

## Interface (Input -> Output)
- Input: a sequence of file-click events
- Output: a growing tab list in the active pane

## Acceptance Criteria
- Each newly clicked (not-yet-open) file adds one tab to the active pane's tab list.
- Tab order reflects the order files were opened (or another defined, consistent order).
