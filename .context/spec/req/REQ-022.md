# REQ-022
- Status: Draft
- Source: SCN-004 Exception (rapid double-split race)

## Requirement
The system shall guard `splitRight()` (or equivalent) so that a second split/render-triggering call cannot start before the first pane-render completes, preventing duplicated pane DOM nodes.

## Interface (Input -> Output)
- Input: two split/render-triggering calls issued in rapid succession
- Output: exactly one consistent pane-render result, no duplicated DOM

## Acceptance Criteria
- Triggering split twice in rapid succession results in exactly two panes, not more.
- `renderPanes()` (or equivalent) is awaited before a subsequent render-triggering call proceeds, eliminating the overlapping-render race observed in the prototype (`splitRight()` calling `renderPanes()` without `await`, which duplicated 2 real panes into 4 DOM elements).
