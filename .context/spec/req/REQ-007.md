# REQ-007
- Status: Draft
- Source: SCN-001 Exception (large-tree scan)

## Requirement
The system shall keep the UI responsive during a scan of a large directory tree, showing a loading indicator rather than blocking the main thread to the point of an unresponsive page.

## Interface (Input -> Output)
- Input: a directory handle with a large number of descendants
- Output: a loading indicator shown during scan; sidebar populated on completion

## Acceptance Criteria
- A loading indicator is visible while a scan is in progress.
- The page remains interactive (e.g., can be scrolled/clicked) during the scan.
