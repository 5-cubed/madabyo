# REQ-002
- Status: Draft
- Source: SCN-001 Flow step 2

## Requirement
The system shall recursively scan a granted directory handle, filter entries to `.md` files, and prune directories with no markdown descendants.

## Interface (Input -> Output)
- Input: a `FileSystemDirectoryHandle`
- Output: a pruned tree data structure containing only markdown files and their ancestor directories

## Acceptance Criteria
- Every `.md` file under the granted root appears in the output tree.
- Every non-markdown file is excluded from the output tree.
- Every directory with zero markdown descendants (direct or nested) is excluded from the output tree.
- A directory containing at least one markdown descendant is retained even if it has non-markdown siblings.
