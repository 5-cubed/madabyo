# REQ-020
- Status: Draft
- Source: SCN-004 Exception (min-width clamp)

## Requirement
The system shall clamp pane resizing at a defined minimum width instead of allowing a pane to collapse to zero.

## Interface (Input -> Output)
- Input: a drag gesture that would take a pane below the minimum width
- Output: pane width clamped at the minimum

## Acceptance Criteria
- Dragging past the minimum-width threshold stops the pane's width at that minimum, not below it.
- Neither pane can be resized to zero or negative width via the divider.
