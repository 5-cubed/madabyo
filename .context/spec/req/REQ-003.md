# REQ-003
- Status: Draft
- Source: SCN-001 Flow step 3

## Requirement
The system shall render the pruned tree in the sidebar using VS Code folder/markdown icon assets, styled in the light theme.

## Interface (Input -> Output)
- Input: the pruned tree data structure
- Output: a rendered sidebar DOM tree

## Acceptance Criteria
- Each folder node displays the VS Code folder icon.
- Each markdown file node displays the VS Code markdown-file icon.
- The sidebar and surrounding chrome use the light theme's color values.
