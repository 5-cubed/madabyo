# REQ-005
- Status: Draft
- Source: SCN-001 Exception (unsupported browser)

## Requirement
The system shall detect the absence of the File System Access API and show an unsupported-browser message instead of invoking the picker.

## Interface (Input -> Output)
- Input: app load / "Open Folder" click in a browser lacking `window.showDirectoryPicker`
- Output: unsupported-browser message shown, picker not invoked

## Acceptance Criteria
- `showDirectoryPicker` is feature-detected before use.
- When absent, an explanatory message is shown in place of the folder-picker action.
