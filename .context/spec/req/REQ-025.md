# REQ-025
- Status: Draft
- Source: SCN-005 Exception (revoked/expired permission)

## Requirement
The system shall prompt the user to re-grant access with a single click when a persisted handle's permission has been revoked or has expired, rather than forcing a full folder re-pick.

## Interface (Input -> Output)
- Input: a persisted handle whose permission check fails
- Output: a single-click re-grant prompt; on grant, the same handle is re-scanned

## Acceptance Criteria
- A permission check (e.g., `queryPermission`/`requestPermission`) runs before using a retrieved handle.
- On denial/expiry, a re-grant prompt is shown instead of silently failing or forcing `showDirectoryPicker()` again.
- Approving the re-grant prompt proceeds to scan the same folder without a new OS folder-picker dialog.
