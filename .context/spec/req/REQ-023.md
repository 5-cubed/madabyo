# REQ-023
- Status: Draft
- Source: SCN-005 (persistence write, implied by "previous session picked a folder")

## Requirement
The system shall persist the granted directory handle (e.g., to IndexedDB) at the point of a successful folder pick.

## Interface (Input -> Output)
- Input: a successful `FileSystemDirectoryHandle` grant
- Output: that handle stored in persistent browser storage

## Acceptance Criteria
- After a successful folder pick, the handle is written to IndexedDB (or equivalent persistent store) before the sidebar populates.
- The persisted handle can be read back in a later page load (verified by REQ-024).
