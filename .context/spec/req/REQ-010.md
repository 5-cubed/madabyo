# REQ-010
- Status: Draft
- Source: SCN-002 Exception (malformed markdown)

## Requirement
The system shall show a rendering-error state in a tab when its file's content fails to parse/render, instead of crashing.

## Interface (Input -> Output)
- Input: file content that raises a renderer error
- Output: a rendering-error state shown in that tab

## Acceptance Criteria
- A renderer exception is caught and does not propagate to crash the app.
- The affected tab shows an explicit error state, not a blank or stale render.
