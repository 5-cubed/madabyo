# REQ-026
- Status: Draft
- Source: SCN-005 Exception (persisted folder gone)

## Requirement
The system shall fall back to the empty/open-folder prompt state when a persisted folder no longer exists at its original location.

## Interface (Input -> Output)
- Input: a persisted handle whose underlying folder is gone
- Output: the empty/open-folder prompt state

## Acceptance Criteria
- A re-scan attempt that fails because the folder is gone does not crash the app.
- The app falls back to the same empty/open-folder prompt state used for a fresh, never-configured session.
