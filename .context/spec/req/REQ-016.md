# REQ-016
- Status: Draft
- Source: SCN-003 Exception (close active tab)

## Requirement
The system shall automatically activate an adjacent tab when the user closes the currently active tab, if any tabs remain.

## Interface (Input -> Output)
- Input: a close event on the currently active tab, with at least one other tab remaining
- Output: a deterministically chosen adjacent tab becomes active

## Acceptance Criteria
- After closing the active tab, exactly one remaining tab becomes active.
- The newly active tab is chosen by a consistent rule (e.g., the tab immediately to the left, or the next one to the right if none).
