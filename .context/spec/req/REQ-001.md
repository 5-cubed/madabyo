# REQ-001
- Status: Draft
- Source: SCN-001 Flow step 1

## Requirement
The system shall let the user grant access to a local folder via the browser's File System Access API folder picker.

## Interface (Input -> Output)
- Input: user-initiated "Open Folder" action
- Output: a `FileSystemDirectoryHandle` for the granted folder, or no handle if the user does not complete the grant

## Acceptance Criteria
- Clicking "Open Folder" invokes `showDirectoryPicker()`.
- A successful grant yields a `FileSystemDirectoryHandle` handed to the scan step (REQ-002).
- No handle is produced if the picker is dismissed without a grant (covered by REQ-004).
