# REQ-017
- Status: Draft
- Source: SCN-003 Exception (close last tab)

## Requirement
The system shall show a pane empty-state, not an error, when the user closes the last remaining tab in a pane.

## Interface (Input -> Output)
- Input: a close event on a pane's only remaining tab
- Output: the pane's empty-state view

## Acceptance Criteria
- Closing the last tab leaves zero tabs and shows the pane's defined empty-state, not a crash or blank area.
