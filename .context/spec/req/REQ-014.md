# REQ-014
- Status: Draft
- Source: SCN-003 Flow step 2 (switch tab)

## Requirement
The system shall make a clicked tab the active tab, displaying its content in the pane.

## Interface (Input -> Output)
- Input: a tab-click event within a pane's tab list
- Output: that tab becomes active; its content is shown

## Acceptance Criteria
- Clicking a non-active tab makes it active and renders its content.
- Only one tab per pane is active at a time.
