# REQ-015
- Status: Draft
- Source: SCN-003 Flow step 2 (close tab)

## Requirement
The system shall remove a tab from its pane's tab list when the user activates its close control.

## Interface (Input -> Output)
- Input: a tab-close event
- Output: the tab list with that tab removed

## Acceptance Criteria
- The closed tab no longer appears in the tab list.
- Closing a non-active tab does not change which tab is active.
