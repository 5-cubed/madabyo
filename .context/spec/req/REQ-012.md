# REQ-012
- Status: Draft
- Source: SCN-002 Exception (already-open file)

## Requirement
The system shall reuse (focus) an existing tab for a file rather than opening a second tab for the same file in the same pane.

## Interface (Input -> Output)
- Input: a clicked file that already has an open tab in the active pane
- Output: focus set to the existing tab; no new tab created

## Acceptance Criteria
- Only one tab per file exists at a time within a given pane.
- Focusing an already-open file's tab does not re-read or re-render its content unnecessarily.
