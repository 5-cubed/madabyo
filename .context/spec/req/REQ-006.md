# REQ-006
- Status: Draft
- Source: SCN-001 Exception (zero markdown files)

## Requirement
The system shall show an empty-state message in the sidebar when the granted folder yields zero markdown files after filtering.

## Interface (Input -> Output)
- Input: a pruned tree with zero entries
- Output: sidebar empty-state message

## Acceptance Criteria
- Zero-result scans render a distinct "no markdown files found" message, not a blank sidebar.
- No error is thrown for a legitimately empty result.
