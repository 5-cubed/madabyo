# REQ-008
- Status: Draft
- Source: SCN-002 Flow step 2

## Requirement
The system shall read a selected file's content via its file handle and render it to HTML with the chosen markdown renderer.

## Interface (Input -> Output)
- Input: a `FileSystemFileHandle` for the clicked file
- Output: rendered HTML content for that file

## Acceptance Criteria
- The file's raw text is fetched via its handle before rendering.
- Rendering produces HTML reflecting the source markdown's structure (headings, lists, code blocks, etc.).
