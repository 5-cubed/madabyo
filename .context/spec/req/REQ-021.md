# REQ-021
- Status: Draft
- Source: SCN-004 Exception (close one pane)

## Requirement
The system shall return to a single full-width pane layout when the user closes one of two split panes.

## Interface (Input -> Output)
- Input: a pane-close event while exactly two panes exist
- Output: the remaining pane rendered at full width

## Acceptance Criteria
- Closing one of two panes results in exactly one pane occupying the full available width.
- The remaining pane's tabs and active tab are unaffected by the other pane's closure.
