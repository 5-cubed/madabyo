# REQ-024
- Status: Draft
- Source: SCN-005 Flow steps 1-3

## Requirement
The system shall, on app load, retrieve a persisted directory handle and automatically re-scan it without showing the folder picker.

## Interface (Input -> Output)
- Input: app load event, with a persisted handle present in storage
- Output: the sidebar populated from a re-scan of that handle, picker not shown

## Acceptance Criteria
- On load, if a persisted handle exists, the picker is not invoked.
- The retrieved handle is re-scanned using the same scan/filter/prune logic as REQ-002, and the sidebar populates from the result.
