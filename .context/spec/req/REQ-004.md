# REQ-004
- Status: Draft
- Source: SCN-001 Exception (picker cancelled)

## Requirement
The system shall leave the sidebar in its empty/prompt state if the user dismisses the folder picker without granting access.

## Interface (Input -> Output)
- Input: picker dismissed/cancelled event
- Output: sidebar remains (or returns to) the empty/prompt state

## Acceptance Criteria
- Cancelling the picker does not throw an unhandled error.
- No stale tree from a previous folder is left rendered if the user cancels a re-pick attempt.
