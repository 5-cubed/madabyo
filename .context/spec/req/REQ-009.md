# REQ-009
- Status: Draft
- Source: SCN-002 Flow steps 1 & 3

## Requirement
The system shall open a new tab for a clicked file's rendered content in the active pane, or focus its existing tab if already open.

## Interface (Input -> Output)
- Input: a clicked sidebar file entry + current pane's tab list
- Output: the active pane's tab list and active-tab selection

## Acceptance Criteria
- Clicking a file not already open in the active pane creates a new tab showing its rendered content.
- Clicking a file already open in the active pane focuses that tab instead of creating a duplicate (paired with REQ-012).
