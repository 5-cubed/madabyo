# REQ-011
- Status: Draft
- Source: SCN-002 Exception (file moved/deleted)

## Requirement
The system shall show a file-not-found state in a tab when its underlying file has been moved or deleted since the scan.

## Interface (Input -> Output)
- Input: a file handle read that fails because the file no longer exists at its scanned location
- Output: a file-not-found state shown in that tab

## Acceptance Criteria
- A failed read due to a missing file is caught and does not crash the app.
- The affected tab shows an explicit file-not-found state, not a blank tab.
