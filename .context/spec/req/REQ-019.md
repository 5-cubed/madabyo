# REQ-019
- Status: Draft
- Source: SCN-004 Flow steps 3 & 4

## Requirement
The system shall let the user resize the two panes by dragging the divider between them, updating pane widths live.

## Interface (Input -> Output)
- Input: a drag gesture on the pane divider
- Output: updated width values for both panes, applied without disrupting their rendered content

## Acceptance Criteria
- Dragging the divider changes both panes' widths in real time as the drag proceeds.
- Releasing the drag leaves the panes at the dragged-to widths.
- Neither pane's rendered tab content is lost or re-rendered incorrectly during a resize.
